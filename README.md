  **The most widely deployed SSH and SFTP server**, BSD-2-Clause licensed. **Included with every Linux distribution** — **the foundation of secure file transfer** . **SFTP server with chroot jails, key-based authentication, and SCP** . **The definitive open-source SFTP implementation** . 🔐

- **[vsftpd](https://github.com/silverwind/vsftpd)** [![Stars](https://img.shields.io/github/stars/silverwind/vsftpd?style=social&color=white)](https://github.com/silverwind/vsftpd/stargazers)

- **[PycURL](https://github.com/pycurl/pycurl)** [![Stars](https://img.shields.io/github/stars/pycurl/pycurl?style=social&color=white)](https://github.com/pycurl/pycurl/stargazers)
